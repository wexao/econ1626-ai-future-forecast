# ECON1626 Assessment 3: AI Future Forecast
 
## Overview
This is an interactive web essay forecasting the impact of AI on administrative and customer service roles in Australia from 2027 to 2030.
 
## Repository Structure
- `README.md`: Project overview and instructions.
- `forecast.html`: The interactive web essay (to be completed).
- `notes.md`: Research notes and source materials.
 
## Data & Sources
- ABS (2026), Labour Force, Australia, Detailed.
- ILO (2025), Generative AI and Jobs, Working Paper 140.
- OECD (2024), AI and Skills Demand.
- Industry Week insights from Maincode, Westpac, Cointree, and Cigno.
